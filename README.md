# ingestor-cf

Library that helps exchange data between Cloud Functions and Ingestor service.

## Installation

```bash
pip install git+https:github.com/livedocs-io/vm-lib.git
```

If you run into any repo permission issues, you can try to run the following command:

```bash
pip install git+https:username:password@github.com/livedocs-io/vm-lib.git
```

## Testing

```bash
python livedocs/test.py
```
